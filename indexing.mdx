Индексация помогает доменам лучше индексироваться Гуглом: меньше «красных» сюрпризов и больше доверия к лендингам. Настраивается один раз через Google Cloud: создаёшь проект, включаешь три API, делаешь сервисный аккаунт и скармливаешь боту JSON-ключ. Дальше всё автоматически.

## По шагам

<Steps>
  <Step title="Создаёшь проект">
    Заходишь на [console.cloud.google.com](https://console.cloud.google.com) → APIs & Services → Enable APIs → Create project → Create → ждёшь около 10 секунд.

    ![Создание проекта в Google Cloud Console](https://mintcdn.com/mercury-84bcef65/EE8PVnofH-JdmHH1/images/image-3.png?fit=max&auto=format&n=EE8PVnofH-JdmHH1&q=85&s=1da7476e2603f52639da869756bd98e7)
  </Step>
  <Step title="Включаешь три API">
    В Enable APIs and services по очереди вводишь и жмёшь Enable для:

    * Site Verification API
    * Search Console API
    * Web Search Indexing API

    После каждого подожди, пока включится, и возвращайся к списку.

    ![Включение API в Enable APIs and services](https://mintcdn.com/mercury-84bcef65/EE8PVnofH-JdmHH1/images/image-13.png?fit=max&auto=format&n=EE8PVnofH-JdmHH1&q=85&s=a7a862612b54d614709dba443034ec57)
  </Step>
  <Step title="Делаешь сервисный аккаунт">
    IAM → Service Accounts → Create Service Account (название любое).

    ![Создание Service Account в разделе IAM](https://mintcdn.com/mercury-84bcef65/EE8PVnofH-JdmHH1/images/image-23.png?fit=max&auto=format&n=EE8PVnofH-JdmHH1&q=85&s=dd8e4ace7d3509efcd8c13e213c09358)
  </Step>
  <Step title="Генерируешь JSON-ключ">
    У созданного аккаунта: три точки → Manage Keys → Add key → Create new key → **JSON** → Create. Файл скачается.

    ![Создание нового JSON-ключа у сервисного аккаунта](https://mintcdn.com/mercury-84bcef65/EE8PVnofH-JdmHH1/images/image-26.png?fit=max&auto=format&n=EE8PVnofH-JdmHH1&q=85&s=8fd76141102c599d2cdfcb3c80fa69e5)
  </Step>
  <Step title="Скидываешь файл боту">
    Просто скидываешь скачанный JSON в чат. Бот подхватит и сам подключит индексацию твоим доменам.
  </Step>
</Steps>
